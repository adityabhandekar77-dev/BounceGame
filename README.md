# BounceGame

A 2D arcade paddle game made in C++ using Raylib.

## Features
- Difficulty selection
- High score saving
- Sound effects and music
- Progressive ball speed
- Multiple lives
- Main menu
- Game over screen

## Built With
- C++
- Raylib
- CMake
- MSYS2 UCRT64

## Build

```bash
cmake -S . -B build
cmake --build build
./build/BounceGame.exe
